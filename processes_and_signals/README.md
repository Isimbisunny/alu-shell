# Processes and Signals

This directory contains Bash scripts for learning how to manage processes and signals in Linux.

## Tasks

### 1. List Your Processes — `1-list_your_processes`

Displays running processes for all users, including processes without a controlling terminal, in a user-oriented format with process hierarchy.

**Command used:** `ps auxf`

## Requirements

- Use Bash scripts.
- Make scripts executable with `chmod +x`.
- Test scripts before committing changes.
- Follow ShellCheck recommendations.
