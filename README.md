# ALU Shell

This repository contains shell scripts for the ALU Shell project.

## Basics

- `basics/0-current_working_directory` - Prints the current working directory.
- `basics/1-listit` - Lists the files in the current directory.
- `basics/2-bring_me_home` - Changes the working directory to the home directory.
- `basics/3-listfiles` - Lists files in long format.
- `basics/4-listmorefiles` - Lists all files, including hidden files, in long format.
- `basics/5-listfilesdigitonly` - Lists files with user and group IDs shown numerically.
- `basics/6-firstdirectory` - Creates a directory in `/tmp`.
- `basics/7-movethatfile` - Moves a file to a directory.
- `basics/8-firstdelete` - Deletes a file.
- `basics/9-firstdirdeletion` - Deletes a directory.
- `basics/10-back` - Changes to the previous working directory.
- `basics/11-lists` - Lists files in multiple directories.
- `basics/12-file_type` - Prints the type of a file.
- `basics/13-symbolic_link` - Creates a symbolic link.
- `basics/14-copy_html` - Copies HTML files to the parent directory.
- `basics/15-lets_move` - Moves files beginning with an uppercase letter.
- `basics/16-clean_emacs` - Removes Emacs backup files.
- `basics/17-tree` - Creates the `welcome/to/school` directory structure.

## Permissions

- `permissions/0-iam_betty` - Switches the current user to betty.
- `permissions/1-who_am_i` - Prints the effective username.
- `permissions/2-groups` - Prints the groups of the current user.
- `permissions/3-new_owner` - Changes the owner of a file to betty.
- `permissions/4-empty` - Creates an empty file.
- `permissions/5-execute` - Adds execute permission to the owner.
- `permissions/6-multiple_permissions` - Adds execute permission to owner and group and read permission to others.
- `permissions/7-everybody` - Adds execute permission to everyone.
- `permissions/8-James_Bond` - Sets permissions so only others have full permissions.
- `permissions/9-John_Doe` - Sets the file permissions to `-rwxr-x-wx`.
- `permissions/10-mirror_permissions` - Makes one file have the same permissions as another.
- `permissions/11-directories_permissions` - Adds execute permission to all subdirectories.
- `permissions/12-directory_permissions` - Creates a directory with specific permissions.
- `permissions/13-change_group` - Changes the group owner of a file.
- `permissions/14-change_owner_and_group` - Changes the owner and group of files and directories.
- `permissions/15-symbolic_link_permissions` - Changes the owner and group of a symbolic link.
- `permissions/16-if_only` - Changes the owner only when the current owner is guillaume.
