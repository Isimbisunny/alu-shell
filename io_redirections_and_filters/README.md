# Shell, I/O Redirections and Filters

This project contains Bash scripts that practice shell input/output redirection, filters, pipes, special characters, and file processing.

## Tasks

* `0-hello_world` - Prints `Hello, World`.
* `1-confused_smiley` - Displays a confused smiley.
* `2-hellofile` - Displays the contents of `/etc/passwd`.
* `3-twofiles` - Displays the contents of `/etc/passwd` and `/etc/hosts`.
* `4-lastlines` - Displays the last 10 lines of `/etc/passwd`.
* `5-firstlines` - Displays the first 10 lines of `/etc/passwd`.
* `6-third_line` - Displays the third line of the file `iacta`.
* `7-file` - Creates a file with the required name and writes `Best School` into it.
* `8-cwd_state` - Writes the long listing of the current directory into `ls_cwd_content`.
* `9-duplicate_last_line` - Duplicates the last line of `iacta`.
* `10-no_more_js` - Deletes all regular `.js` files in the current directory and its subdirectories.
* `11-directories` - Counts all directories and subdirectories in the current directory.
* `12-newest_files` - Displays the 10 newest files in the current directory.
* `13-unique` - Displays words that appear exactly once and sorts them.
* `14-findthatword` - Displays lines containing the word `root` from `/etc/passwd`.
* `15-countthatword` - Counts the lines containing `bin` in `/etc/passwd`.
* `16-whatsnext` - Displays lines containing `root` and the next three lines.
* `17-hidethisword` - Displays lines from `/etc/passwd` that do not contain `bin`.
* `18-letteronly` - Displays lines from `/etc/ssh/sshd_config` that start with a letter.
* `19-AZ` - Replaces characters `A` and `c` with `Z` and `e`.
* `20-hiago` - Removes all `c` and `C` characters from input.
* `21-reverse` - Reverses input.
* `22-users_and_homes` - Displays users and their home directories from `/etc/passwd`, sorted by username.
* `23-empty_casks` - Finds all empty files and directories.
* `24-gifs` - Lists `.gif` files recursively, removes the extension, and sorts them case-insensitively.
* `25-acrostic` - Displays the first character of each line.
* `26-the_biggest_fan` - Displays the 11 hosts with the most requests in the provided log data.

## Learning Objectives

By completing this project, I practice:

* Using `head`, `tail`, `find`, `wc`, `sort`, `uniq`, `grep`, `tr`, `rev`, and `cut`.
* Redirecting standard output to files.
* Reading standard input from files.
* Using pipes to send the output of one command to another.
* Combining commands and filters.
* Understanding shell special characters.
* Working with `/etc/passwd` and `/etc/shadow`.
* Using Bash scripts to automate common shell operations.

## Requirements

* All scripts use `#!/bin/bash` as the first line.
* All scripts are exactly two lines long.
* All scripts end with a new line.
* All scripts are executable.
* The scripts are written for Ubuntu 20.04 LTS.
* The scripts do not use backticks, `&&`, `||`, or `;`.
* The project follows the required shell and I/O redirection guidelines.
